# Atividade React (simples)

Projeto com os 6 componentes: acordeão, paginação, barra de progresso, abas, menu suspenso e notificação toast.

## Executar no GitHub Codespaces

1. Coloque estes arquivos em um repositório do GitHub e abra no Codespaces.
2. No terminal, execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço mostrado na aba **Ports** do Codespaces.

Para o vídeo obrigatório, mostre rapidamente os 6 componentes na tela e depois o arquivo `src/App.jsx` e a pasta `src/components`.
